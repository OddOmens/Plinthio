## Decisions

- **A minor, not a major.** Nothing needs changing on upgrade. The ratings table is rebuilt to
  allow half stars (in a transaction, existing whole-star ratings kept), and the pre-upgrade
  backup covers it.
- **API keys stay usable on admin and editor routes** with their owner's role. The API docs promise
  it and the intro/credits markers can only be set by script. What changed is that a key can no
  longer be exchanged for a session (`/api/auth/refresh`) or used to make or list keys.
- **CORS default unchanged** (`*`); every API route still needs a token.
- **Docker IPv6.** With an IPv6 port mapping, Docker can present outside visitors as the bridge
  address, which looks like home. Documented in docs/remote-access.md: keep the shipped
  `0.0.0.0` mapping.

## Client impact

- Turning on two-factor now signs out the account's other sessions. `POST /api/auth/2fa/enable`
  returns a fresh `token` and `mediaToken` for the device that turned it on; the web app stores
  them. An app that ignores them is asked to sign in again.
- `POST /api/auth/refresh` and `/api/keys` refuse API keys (P003). The Apple apps and the
  Android TV app use sign-in tokens, so they're unaffected.
- New optional setting `TRANSCODE_LIMIT` (server-wide cap on video conversions, default 4).
