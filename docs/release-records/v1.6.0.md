## Decisions

- **1.6.0, a minor bump.** Live TV is a new feature, off by default, and nothing changes for
  anyone who doesn't turn it on. The new tables are added on start; no settings or volumes
  change.
- **Live TV ships off.** An admin turns it on in Admin → Live TV (`liveTvEnabled`).
- **Sources:** iptv-org public lists (Unlicense; Plinthio stores the list address only, adult
  channels excluded) and the admin's own M3U + XMLTV. A FastChannels server and HDHomeRun tuners
  were left out for now. The FastChannels repository has no licence, so none of its code or
  lists are used.
- **Defaults hide region-locked channels and the `jmp2.uk` host** (about 14% of the US list:
  a third-party redirect of streams from commercial apps). Admins can show either.
- **One-time acknowledgement** before the first public list, enforced by the server.
- **Streams and logos are relayed** through signed URLs under `/api/media/live`, with the
  address guard in `safeFetch.js` (private/loopback/metadata addresses refused at connect time
  and on each redirect). Only an admin's own playlist on a plainly local host may reach the
  home network.
- **Channel health must stay light on CPU/GPU** (the user's requirement): network-only, 20
  channels per 10 minutes, two at a time; measured at 0.03% CPU on the test server.
- **Line-ups are named neutrally** ("selection" and its equivalents) in every language, never a
  word that suggests a paid package.
- **Changelog:** the PR's single Live TV entry was split into five user-facing points for the
  release notes, and a short security line was added for #59/#60. Dependabot updates don't
  usually get changelog lines; these two do because they closed open security alerts.

## Manual steps / follow-ups

- After merging: tag `v1.6.0`, watch the Release workflow, then update 8088 (it runs the GHCR
  `latest` image: pull + `up -d` with `docker-compose.yml`, the override and
  `-f docker-compose.tailscale.yml`), and check `/api/health` and the Funnel address.
- Known limit: a few channels only offer IPv6, and Docker's default network is IPv4-only, so
  those fail through the relay. Documented in `docs/live-tv.md`.
- Not in 1.6.0: recording or pausing live TV, antenna tuners, non-HLS streams.
