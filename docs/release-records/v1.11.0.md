## Decisions

- **A minor, not a major.** Nothing needs changing on upgrade. The one thing a person may
  choose to do is in the changelog's Security section: re-make KOReader keys if a copy of the
  database or a backup may have been read by someone else.
- **Converted copies are H.264 only.** An HEVC option was dropped: not every server's graphics
  chip can encode it, and H.264 plays everywhere.
- **Everything new is off until set up.** Converting new videos automatically, replacing
  originals, sending requests to Seerr and approving requests automatically all start off.
  Subtitles by default starts off as well.
- **Accounts with Kids Mode or an age rating limit are never approved automatically.**
- **A request is marked as added by a scan once only**, so one a reviewer moves back stays
  where they put it.
- **Text size, light or dark, font, poster size and reduce motion are kept per device** and
  can't be locked by an admin. Home rows follow the account.
- **The two named fonts ship with Plinthio** (both OFL-1.1, texts served at `/licenses/` and
  listed in `THIRD_PARTY_NOTICES.md`), so nothing is fetched from another site.
- **The review queue says Approve in English only.** The other ten languages keep the word they
  already used.
- **KOReader sync keys are stored as a one-way hash.** Existing keys are converted on start and
  KOReader needs no change.

## Client impact

- Apps can send `?videoCodecs=h264,hevc` to say which video codecs the device plays; anything
  else is converted to H.264 as it streams, or served from a converted copy.
- `/customization` gains `subtitles: { on, language }`; accounts gain `preferences.subtitles`.
- New routes `GET`/`PUT /settings/requests`; review rows carry `will_forward`.
- New error codes: P310, P311, P312 (converting) and P507 (Seerr could not be reached).
- An API key can no longer reset its own owner's password or two-factor.
- Database: `items` gains `imdb_id`, `tvdb_id`, `file_ids`; `media_requests` gains the
  `forward_*` columns, `auto_accepted` and `auto_added_at`; `users` gains `totp_pending_at`.
- The request line in the server's output has a new shape (address first, user agent last, no
  colours). Anything that reads those lines needs its pattern updated.
