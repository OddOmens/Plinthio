## Decisions

- **1.5.0, not 1.4.3.** The user first asked for 1.4.3. They chose 1.5.0 once it was clear
  that `main` already held three features besides translations, and RELEASING.md says new
  features are a minor bump.
- **Own `t()`, not vue-i18n.** The CSP forbids `unsafe-eval`, which vue-i18n's runtime
  message compiler can need. The module in `frontend/src/i18n/` is a few dozen lines, with no
  dependency to keep updated.
- **Translations live in the repo:** `frontend/src/locales/<lang>/<namespace>.json`, 22
  namespaces, 2,462 messages per language. English is bundled (about 44 KB gzipped) and is the
  fallback; every other language loads only when someone picks it.
- **The language is saved per account** (`preferences.language`); a device remembers
  `plinthio_language` for the sign-in page. Admins can't lock it.
- **`npm run check:i18n` runs in CI.** It checks that every key exists in every language,
  that placeholders match, that each language has the plural forms it needs (Polish needs
  four), and that every `t('…')` used in code exists.
- **Tone of address:** de *du*, fr *vous*, es *tú*, it *tu*, nl *je*, pl *ty*, pt-BR *você*,
  zh 你, ja です/ます, ko 해요체. See `docs/translating.md`.
- **Not translated yet:** API error text from the server, the `/api/errors` code entries, and
  metadata from TMDB (statuses, crew jobs).
