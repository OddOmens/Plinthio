backend libraries. No code changes. User-facing notes live in [CHANGELOG.md](../../CHANGELOG.md);
the routine lives in [RELEASING.md](../../RELEASING.md).

## Decisions

- **AGPL-3.0, not GPL-2.0.** A GPL-2.0 `LICENSE` was briefly on `main`. GPL-2.0-only can't be
  combined with dependencies Plinthio ships: Apache-2.0 (`sharp`, `hls.js`, `localforage`) and
  LGPL-3.0 (`libvips` via sharp). The v3 licenses can. AGPL's network clause also keeps a
  modified Plinthio run as a hosted service open, the closest open-source match to the old
  noncommercial intent. The `LICENSE` file is GitHub's canonical text so the license is detected.
- **Commercial use is now allowed** by the license, as with any open-source license. The
  built-in TMDB key is still only in the official, free images (see RELEASING.md).
- **A patch, not a minor.** Nothing changes for users or admins; the license and dependency
  updates need no action.
- **Lockfile patched by hand for #66.** The local npm (10.8.2) drops the `libc` fields that npm 11
  writes, which tell the Docker build's npm which sharp binary to use. Only the multer and undici
  entries were changed.
- **Image label.** `docker/metadata-action` takes `org.opencontainers.image.licenses` from
  GitHub's detected license. 1.6.0 and earlier say `NOASSERTION`; from 1.6.1 it should say
  `AGPL-3.0`.
