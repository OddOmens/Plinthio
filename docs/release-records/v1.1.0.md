## Decisions

- **Opening sequence ships a built-in clip but stays off.** `backend/assets/default-intro.mp4`
  (4 s, 1080p, H.264 at 36 Mbps, silent) is the default; an admin switches it on. Bump
  `DEFAULT_INTRO_VERSION` in `services/intro.js` whenever that file changes, or browsers keep
  the cached copy.
- **Page width is per user, full width by default.** Contained restores the 1.0 layout.
- **Backdrops and logos come with the credits request** (`append_to_response=images`), so no
  extra TMDB call. Credits cached before 1.1.0 refresh on the next open of each title.
- **Held for their own upgrades:** Express 5 (#10), Tailwind 4 (#11), Vite 8 (#16) and
  vue-router 5 (#17, needs Vite 7+). Closed with notes; `dependabot.yml` skips their major
  versions and groups the rest.
- **GitHub hardened** (2026-09-28): rulesets "Protect main" and "Protect release tags"
  (admins bypass), CODEOWNERS, private vulnerability reporting, Dependabot security updates,
  and approval before Actions run on any outside contributor's PR.
