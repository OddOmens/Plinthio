## Decisions

- **Built-in HTTPS on 8443, on by default in Docker.** A local CA is made on first start and
  installed once per device. It's name-constrained to private IPs and local names.
- **Hardened in review** (`78c6e3a`):
  - Learned addresses (from `Host` headers, which anyone can send before signing in) are
    capped at 16 and no longer rotate, so a flood of made-up names can't evict real
    devices' addresses or keep re-issuing the certificate.
  - `.ts.net` dropped from the CA's permitted names: it covers every Tailscale user, so a
    leaked CA key could have impersonated all of them. A tailnet name goes in
    `TLS_HOSTNAMES`.
  - `TLS_HOSTNAMES` is validated before it reaches the openssl config.
- **HSTS:** off whenever Plinthio serves HTTPS itself, since HSTS is per host, not per port,
  and would lock browsers out of plain HTTP on 8088. Installs behind a reverse proxy get
  helmet 8's 365 days. The idea of pinning 180 days was dropped.
- **Browser tests are a required check** on `main` ("Protect main" ruleset), alongside
  Backend tests, Frontend build and Docker image builds.

## Manual steps

1. Merge the release PR.
2. `git checkout main && git pull`, then `git tag v1.2.0 && git push origin v1.2.0`.
3. Watch the Release workflow.
4. On a server upgraded from 1.1.0, port 8443 is new: publish it in the compose file (the
   shipped `docker-compose.yml` already does) and install the CA on each device from
   Docs → PWA Mobile App Setup.
