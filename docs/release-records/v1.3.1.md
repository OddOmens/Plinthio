## Decisions

- **Version 1.3.1, as the user asked.** Strictly, the Appearance tab and the new accent
  colours are features, which RELEASING.md would call a minor bump (1.4.0). The user chose a
  patch: the changes finish and tidy 1.3.0's personalization rather than adding a new area,
  and nothing needs doing when upgrading.
- **No data changes.** The only backend change is the list of allowed accent colours; no
  migrations. Rolling back to 1.3.0 works, but an accent that only exists in 1.3.1 (red,
  orange, lime, teal, blue, purple, fuchsia, pink) would need picking again.
